# Изменения шаблона бэкенда на Go

По этому файлу панель показывает «Что изменилось» и собирает промпт для ИИ-агента, который переносит обновление в код сервиса. Новые версии — сверху.

Формат версии: заголовок «## vX.Y.Z — ГГГГ-ММ-ДД», строка «Обязательное: да» (без обновления выкатка сломается) или «нет», пункты для людей, подраздел «### Для агента» с шагами переноса. Проверки и смену метки `.paas/template` панель добавляет в промпт сама.

## v0.10.2 — 2026-11-21

Обязательное: нет

- `CHANGELOG.md` в формате для обновления промптом: дата, обязательность и шаги для агента у каждой версии.

### Для агента

1. Замени `CHANGELOG.md` сервиса на `CHANGELOG.md` шаблона.

## v0.10.1 — 2026-11-19

### Для агента

1. В `.github/workflows` замени образ проверки `paas.toml` на `ghcr.io/paas-arch/paas-check:1`.

## v0.9.0 — 2026-11-17

Обязательное: нет

- У воркеров и кронов в `paas.toml` появилось поле `description`: одна строка о том, что делает процесс, панель показывает её в списке.

### Для агента

## v0.8.0 — 2026-11-17

Обязательное: нет

- Задачи по расписанию: папка `cmd/cron/<имя>` и запись `[[crons]]` с расписанием в UTC. Сборка собирает их образы.
- Выключенный крон-пример `cmd/cron/example`.

### Для агента

1. Перенеси из шаблона сборку образов `cmd/cron/*` в `.github/workflows`.

## v0.7.0 — 2026-11-17

Обязательное: да

- Воркер запускается, только если у него есть запись `[[workers]]` с `enabled = true`. У воркера-примера она есть.

### Для агента

1. Для каждого воркера в `cmd/workers/<имя>` добавь в `paas.toml` запись `[[workers]]` с `name = "<имя>"` и `enabled = true`, как в шаблоне. Без записи воркер не запустится.
