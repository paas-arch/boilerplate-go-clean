# Изменения шаблона бэкенда на Go

Панель показывает здесь, что нового в шаблоне, и по кнопке «Обновить» открывает PR с этими изменениями в репозитории сервиса. Новые версии — сверху; у каждой раздел «## vX.Y.Z».

## v0.10.1

- Сборка проверяет `paas.toml` образом `ghcr.io/paas-arch/paas-check:1`: проверялка переехала в организацию `paas-arch`, прежний образ больше не обновляется.

## v0.10.0

- Список изменений шаблона в `CHANGELOG.md`: по нему панель предлагает обновление.

## v0.9.0

- У воркеров и кронов в `paas.toml` появилось поле `description`: одна строка о том, что делает процесс, панель показывает её в списке.

## v0.8.0

- Задачи по расписанию: папка `cmd/cron/<имя>` и запись `[[crons]]` с расписанием в UTC. Сборка собирает их образы.
- Выключенный крон-пример `cmd/cron/example`.

## v0.7.0

- Воркер запускается, только если у него есть запись `[[workers]]` с `enabled = true`. У воркера-примера она есть.

## v0.6.0

- База в `paas.toml` включена по умолчанию (`[postgresql] enabled = true`), подсказки о базе ведут в `paas.toml`.

## v0.5.0

- Файл `paas.toml` с пояснениями: копии, размер, база, воркеры и переменные сервиса. Сборка проверяет его шагом «Проверка paas.toml».

## v0.4.1

- Воркер один раз при старте предупреждает, что база не подключена, вместо сообщения на каждом круге.

## v0.4.0

- Сервис стартует без базы: ручки примера отвечают 503 «База данных не подключена».

## v0.3.1

- Поля вызова передаются в Sentry; логгер не падает на ошибке-указателе nil.

## v0.3.0

- В логе сообщение и поля разделены: пары ключ–значение и ошибка пишутся отдельными полями JSON.

## v0.2.0

- Правило слоёв без имени модуля: панель переименовывает модуль при создании сервиса.

## v0.1.0

- Первая версия: API с примером, воркер, миграции, сборка в GHCR и правила для агента.
