# Правка paas.toml

Правила — раздел «paas.toml» правила `.claude/rules/go-clean.md`. Переменные и секреты — `env.md`, воркеры — `worker.md`, кроны — `cron.md`.

Файл — это то, что работает на сервере после раскатки версии. Правка — обычный коммит в `main`; на сервере она появится, когда человек раскатит эту версию в панели.

| Нужно | Правка |
|---|---|
| Сервис не должен проседать при перезапуске | `[service] replicas = 2` |
| API не хватает памяти (в журнале OOM, перезапуски) | `[service] size = "medium"`, затем `"large"` |
| Сервису нужна база | рецепт `database.md` |
| Код требует новой функции Postgres | `[postgresql] version = <номер>` |
| Поменять подпись сервиса в панели | `description = "..."` |

- `replicas` — от 1 до 10. `size` — `small` (128 МиБ), `medium` (512 МиБ), `large` (2048 МиБ) на копию. Каждая копия и размер расходуют память сервера проекта: не поднимай без причины.
- База выключается `enabled = false`: данные остаются, миграции не идут, процессы не получают `DATABASE_DSN`. Если код работает с базой, он перестанет стартовать — выключай, только когда код базу больше не использует.
- `name` не меняй никогда. Ключи, которых нет в файле шаблона, не придумывай: неизвестный ключ — ошибка сборки.

Проверка — `check.md`: шаг с `paas-check` покажет ошибку с номером строки.
