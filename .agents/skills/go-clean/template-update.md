# Обновление шаблона из промпта панели

Промпт панели начинается словами «Обнови сервис … с шаблона go-backend …» и содержит шаги из `CHANGELOG.md` шаблона, ссылку на сравнение версий и проверки. Шаги промпта главнее этого рецепта; здесь — как их выполнять, не сломав сервис.

1. **Не копируй файлы шаблона поверх.** Код сервиса после создания меняли. Переноси изменение в смысле: нашёл в шаблоне правку функции — найди ту же функцию у себя и поправь её.
2. **Модуль Go.** В шаблоне модуль `app.internal`, в сервисе — из первой строки своего `go.mod`. В переносимом коде подставляй свой.
3. **Файлы агента, образцов и меток заменяются целиком:** `.agents/`, `.claude/`, `_examples/`, `CHANGELOG.md`. Ссылки (`.claude/skills/go-clean`, `AGENTS.md`, `GEMINI.md`) остаются ссылками. Свои правки в них, если человек их делал, перенеси в новый текст и скажи ему об этом.
4. **`paas.toml`.** Переноси только новые ключи и комментарии; значения сервиса (`name`, копии, размер, переменные, воркеры, кроны) не трогай.
5. **Примеры шаблона** (`greetings`, `notes` в старых версиях). Если в сервисе их уже убрали, правки, относящиеся только к примеру, пропусти. `_examples/` заменяется целиком.
6. **Шаг «сверься по ссылке»** — пройди по списку изменённых файлов сравнения и для каждого реши: перенести, пропустить (код сервиса) или уже сделано шагом выше. Удалённые в шаблоне файлы удали, если сервис их не менял.
7. **Проверки** — `make check` (`check.md`), затем те, что в промпте.
8. **Метка `.paas/template`** — последним шагом и только после зелёной проверки, ровно на значение из промпта.
