# Переменная или секрет

Правила — разделы «paas.toml» и «Журнал и секреты» правила `.claude/rules/go-clean.md`.

Секрет — то, что нельзя класть в git: ключ API, пароль, токен. Остальное — обычная переменная.

1. **`internal/config/app.go`** — поле в `Config`:

```go
// <зачем, если неочевидно>
StripeKey string `env:"STRIPE_KEY"`
```

   Значение по умолчанию — `env-default:"..."`. Обязательная настройка — проверка в `Config.Validate` с понятным текстом ошибки.
2. **`paas.toml`**, секция `[env_vars]` — тем же коммитом:

```toml
[env_vars]
LOG_LEVEL = "info"   # обычная: значение в git и в панели
STRIPE_KEY = ""      # секрет: значение вводят в панели
```

   Значение — всегда строка в кавычках, даже число: `TIMEOUT_SECONDS = "30"`. Нельзя объявлять `DATABASE_DSN`, `BACKEND_URL`, `APP_PORT`.
3. **`.env.example`** — строка с безопасным локальным значением и комментарием; настоящий ключ — только в своём `.env` (в git он не попадает).
4. Значение берётся из `cfg` в `main.go` и передаётся в `New(...)` клиента или сервиса. Другие пакеты env не читают.
5. **`ARCHITECTURE.md`**, раздел «Configuration» — строка с назначением.
6. Скажи человеку: после раскатки секрет нужно заполнить в панели на вкладке «Секреты» сервиса, иначе процесс получит пустую строку.

Затем `check.md`.
