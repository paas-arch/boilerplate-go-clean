# Образцы

Готовый код, который сервис берёт себе, когда он понадобится. Go эту папку не собирает и не проверяет: имя начинается с `_`. Файлы лежат по тем же путям, куда их копировать.

- `postgres/` — база: подключение, локальный Postgres, команды make, миграция, таблица, сервис над ней. Рецепт — `.claude/skills/go-clean/database.md`.
- `worker/` — фоновый процесс. Рецепт — `.claude/skills/go-clean/worker.md`.
- `cron/` — задача по расписанию. Рецепт — `.claude/skills/go-clean/cron.md`.

Скопированный файл — уже код сервиса: правь его под задачу. Папку `_examples/` не удаляй, она обновляется вместе с шаблоном.
